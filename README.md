# Little Learners Survey

A survey form for a kids' learning platform. Parents fill it out in React,
and on submit the Python backend emails you every answer.

```
kids-survey/
├── backend/          FastAPI service that sends the email
│   ├── app.py
│   ├── requirements.txt
│   └── .env.example
└── frontend/         React (Vite) form
    ├── index.html
    └── src/
        ├── App.jsx
        ├── App.css
        └── main.jsx
```

## 1. Backend setup

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# edit .env with your SMTP details (see comments inside the file)

uvicorn app:app --reload --port 5000
```

The API runs at `http://localhost:5000`. Health check: `GET /api/health`.
Interactive docs (auto-generated by FastAPI): `http://localhost:5000/docs`.

**Gmail users:** turn on 2-Step Verification, then create an App Password at
https://myaccount.google.com/apppasswords and use that (not your normal
password) as `SMTP_PASSWORD`.

## 2. Frontend setup

```bash
cd frontend
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

The frontend calls `http://localhost:5000/api/submit-survey` — update
`API_URL` at the top of `src/App.jsx` if you deploy the backend elsewhere.

## How it works

1. A parent fills out the form (child's info, favorite subjects, learning
   style, a 1-5 star rating, and free-text feedback).
2. On submit, the React app POSTs the answers as JSON to `/api/submit-survey`.
3. Flask formats the answers into a plain-text email and sends it via SMTP
   to the address set in `MAIL_TO`.
4. The parent sees a friendly "all done" confirmation screen.

## Customizing

- **Add/remove questions:** update `FIELD_LABELS` in `backend/app.py` and the
  matching input in `frontend/src/App.jsx`.
- **Change colors/fonts:** all design tokens are CSS variables at the top of
  `frontend/src/App.css`.
- **Use a transactional email service instead of SMTP** (e.g. SendGrid,
  Postmark, Resend): swap out the `send_email` function in `backend/app.py`.
